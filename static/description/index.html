Car Rental

Online bokning och uthyrning av bilar via din Odoo-webbplats.

Funktioner

  • Visa tillgängliga bilar (modell, registreringsnummer, kategori m.m.).
  • Kunden väljer datum/tid, bil och tillval.
  • Skapar offert/försäljningsorder automatiskt vid bokning.
  • Status: bokad, utlämnad, återlämnad, avbokad.
  • Integration med Försäljning/Invoicing för fakturering.
  • Prislistor per dag, vecka, månad, extra kilometer osv.

Vidareutveckling

  • Integration med Fleet/Rental.
  • Kalenderöversikt över bokningar.
  • Automation: påminnelser via e‑post/SMS.
